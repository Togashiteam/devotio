# Implementation Plan: Mobile-First App Pages (001-app-pages-ui)

**Branch**: `001-app-pages-ui` | **Date**: 2026-02-18 | **Spec**: [specs/001-app-pages-ui/spec.md](../001-app-pages-ui/spec.md)  
**Input**: Feature specification from `/specs/001-app-pages-ui/spec.md`

## Summary

Build a sleek, mobile-first PWA-ready static web app ("Devotio") with five pages — Home, Bible Reading, Prayer, Community, and About Us — using Next.js 14 (static export), TypeScript, Tailwind CSS, Framer Motion, and Zustand. All content is served from embedded JSON mock-data files. No backend, no authentication, no database. Session-scoped state (comments, favorites, RSVPs, focus timers) is held in Zustand stores and reset on page reload.

## Technical Context

**Language/Version**: TypeScript 5.x / Node.js 20 LTS  
**Framework**: Next.js 14 — App Router, `output: 'export'` static mode  
**Primary Dependencies**:
- `next` 14 + `react` 18 + `react-dom` 18
- `tailwindcss` 3 — mobile-first utility CSS
- `framer-motion` 11 — smooth page/component transitions (Native-Like UX constitution requirement)
- `zustand` 4 — lightweight reactive session-scoped state
- `@ducanh2912/next-pwa` — PWA manifest + service-worker offline shell
- `lucide-react` — icon set
- `clsx` + `tailwind-merge` — conditional class utilities

**Storage**: Static JSON files under `src/data/` — no database, no API calls  
**Testing**: Jest + React Testing Library (unit/component); Playwright (E2E acceptance tests mapped to Spec Kit scripts T1–T6)  
**Target Platform**: Modern mobile browsers (Chrome/Safari on iOS & Android) + responsive desktop; PWA-installable  
**Project Type**: Web — Next.js static export (single project)  
**Performance Goals**: LCP ≤ 2.5 s on simulated 3G; INP ≤ 200 ms for primary interactions; CLS < 0.1 on Community feed  
**Constraints**: No backend; session state only (reset on reload); offline shell via service worker; HTTPS-only in production; WCAG 2.1 AA; touch targets ≥ 44×44 px; no horizontal scroll at 360 px viewport width  
**Scale/Scope**: 5 pages, ~40 components, 12 mock JSON fixtures, 46 FRs, 36 SCs; prototype/demo scale
